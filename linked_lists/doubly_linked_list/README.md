# Doubly Linked List 🔗

This directory contains my Python implementation of a Doubly Linked List using nodes.

## 📚 Operations Implemented

- Insertion at the beginning and end
- Insertion at a specific index
- Insertion after a given value
- Deletion from the beginning and end
- Deletion at a specific index
- Deletion of a given value
- Forward and backward traversal
- Counting the number of elements

## 💻 Language
Python

## 🎯 Objective
To understand doubly linked list operations and learn how to manage `prev` and `next` pointers.
